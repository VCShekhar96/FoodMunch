# FoodMunch

A frontend food and restaurant-themed web project focused on responsive layout, navigation, and user-facing content.

## Goals
- Practice responsive frontend development
- Build reusable page sections
- Improve layout, typography, and mobile presentation

## Run Locally
Open the project files in a local development server or follow the setup instructions contained in the application source.
